# Maali Vet Care - Site Estático

Site estático da clínica veterinária Maali Vet Care, pronto para GitHub Pages.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub (pode ser público ou privado).
2. Faça upload de **todos os arquivos e pastas** desta pasta `maalivet` para a raiz do repositório.
   - Ou arraste a pasta inteira.
3. Vá em **Settings → Pages**.
4. Em "Source", escolha a branch `main` (ou `master`) e pasta `/ (root)`.
5. Salve. Em alguns minutos o site estará no ar em `https://seu-usuario.github.io/nome-do-repositorio/`.

## Estrutura

- `index.html` → Página inicial (Sobre)
- `servicos.html` → Grade de serviços
- Páginas individuais de cada serviço
- `css/style.css` → Estilos
- `imagens/` → Todas as imagens
